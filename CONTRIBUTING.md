# Contributing

[日本語](CONTRIBUTING.ja.md)

Contributions may add sources, improve classification, fix methodology, or improve the static
report. Keep measurement and interpretation separate: do not add recommended levels, safety
labels, rankings, or uncited claims to canonical data.

Follow [`docs/updating.md`](docs/updating.md) for snapshot changes. Every data change must retain
source provenance, pass schema and cross-record validation, update generated CSV/site files, and
contain no original audio, downloaded vendor package, or extracted application. Use an official
source and document an explicit gap when a package cannot be obtained without installation or
access-control circumvention.

Code is contributed under MIT; data and documentation under CC BY 4.0. By contributing, you
confirm that you have the right to provide the contribution under those terms.
