# 文書の決定

[English](documentation.md)

このリポジトリの文書について閉じた判断を持つ。英語と日本語の対の置き方は
[`AGENTS.md`](../../AGENTS.md) にある。

## 各 H1 の下の相互リンクの行

- **決定**（2026-10-20）: 対になった文書の H1 の下の行は、リンクだけにする。英語版は
  `[日本語](<name>.ja.md)`、日本語版は `[English](<name>.md)` とする。
- **却下した案**: 引用の行に文で書く形（`> 日本語版は … を参照してください.`）。
  [#61](https://github.com/semnil/notification-sound-db/pull/61) の作業のときに示され、退けた。
  この形をもう一度提案しない。

## 日本語版の 固有 と 測定失敗 は意図して残している

2 つの訳語がそれぞれ何に合わせたものかは、残すと決めた pull request にある:
[#61](https://github.com/semnil/notification-sound-db/pull/61)。
