# 要件定義

[English](requirements.md)

ステータス: 2026-08-09 初期要件合意済み

## 1. 目的

OS および主要アプリケーションに同梱されたイベント音ファイルを同一条件で測定し、YouTube
ライブなどの視聴中に通知音が同時再生される場面を検討するための、説明可能で再現可能な参照
データを提供する。主な利用場面は視聴者端末上でライブ音声とローカル通知音が競合する状況とする。
通知音を配信音声に載せた配信者側の資料としての利用は副次的用途とする。

## 2. 非目標

- 配信音量の推奨値や下限値を提示しない。
- 「安全」「危険」などの判定を行わない。
- アプリケーションの優劣やランキングを提示しない。
- 音源ファイルの測定値を、実際の再生音圧として扱わない。

OS、アプリケーション、プレイヤー、ミキサー、再生機器の設定により実際の相対レベルが変化する
ことを明記する。将来解釈を追加する場合も測定データとは分離する。

## 3. コンテンツの優先度

通知音との競合を考える際の背景上の優先度は、人の会話、ゲーム音・カラオケ音源などの主要
コンテンツ、一時的にマスクされても影響が小さい BGM の順とする。この優先度は測定項目を選ぶ
背景情報であり、スコアや推奨値には使用しない。

## 4. 初期対象

- macOS のシステムイベント音
- Apple 標準アプリケーション
- Slack
- Discord
- Microsoft Teams
- Zoom
- LINE

新しい OS、アプリ、音源形式、測定指標を追加できる構造とする。公開データは測定時点の最新
バージョンだけを保持し、更新時は旧レコードを置き換える。過去状態は Git 履歴で参照し、現行
スナップショットから参照されなくなった測定値は現行データセットに残さない。

### 4.1 収録するイベント音

バックグラウンドイベントまたはユーザー操作で再生される短い音を対象とする。メッセージ、着信、
通話状態、エラー、処理完了、UI フィードバックを含み、音楽、動画、読み上げなど主要コンテンツは
除外する。分類 ID は `message`、`incoming_call`、`call_state`、`error`、`completion`、
`ui_feedback`、`system_alert`、`unknown` とする。分類は音源ハッシュの測定値から分離し、用途が
不明なものを推測で除外せず `unknown` として保持する。

## 5. 音源の取り扱い

- 正規化、ゲイン変更、リサンプリング、不可逆変換をせず、同梱ファイルを測定する。
- SHA-256、アプリ内相対パス、OS／アプリ版、取得来歴だけを保持し、元音源は保存しない。
- 未導入アプリは公式配布物を一時領域に取得できるが、インストール・実行しない。URL と配布物の
  SHA-256 を記録し、測定後は配布物、展開済みアプリ、元音源を削除する。
- 認証、暗号化、アクセス制御、DRM を回避しない。取得できない対象は未収集として明示する。

## 6. 測定項目

Integrated LUFS、最大 Momentary LUFS（400 ms）、最大 Short-term LUFS（3秒）、LRA、True Peak、
Sample Peak、全区間／有音区間 RMS、Crest Factor、長さ、無音区間、チャンネル別レベル、周波数帯別
エネルギー、重複なしの短時間 RMS 包絡線（最大400点）、スペクトル重心、ピーク周波数、
200 Hz–8 kHz エネルギー比、形式・ツール・実行日時を記録する。厳密なパラメーターは
`config/analysis-profile.json` と測定方法文書で版管理する。

## 7. データと公開方法

- GitHub に保存し、GitHub Pages で静的 HTML レポートを公開する。
- 整形済み JSON を正本とし、ハッシュ単位の測定値と現行アプリ内の参照を分離する。
- JSON Schema で検証し、JSON から CSV と HTML を再生成できるようにする。
- リポジトリ、フィールド名、単位識別子、分類 ID は英語を正本とし、主要文書とサイトに日本語を
  併設する。
- 初期版はローカル CLI で手動更新する。Actions は検証、再生成確認、サイト構築、Pages 配備を
  担当し、定期更新は行わない。

## 8. 根拠と再現性

規格、ツール版、パラメーター、測定日時、ハッシュ、取得来歴を記録する。規格外の記述的指標は
計算式と目的を明記する。

## 9. ライセンス

コードは MIT、測定データと文書は CC BY 4.0 とする。元音源は収録せずライセンス対象外とし、
製品名、商標、元音源の権利は各権利者に帰属する。

## 10. 静的サイトの情報設計

機能と全体の雰囲気は <https://ai-compare.semnil.com/ja/> と
<https://koe-zukan.semnil.com/> を参考にし、意匠は複製しない。中央寄せで情報密度の高い構成、
目立つ検索・絞り込み、全データ列の昇順・降順ソート、一覧から詳細への導線、件数と日時、
値・単位・来歴・注意事項の明確な区別、英日切り替え、モバイル・キーボード・no-JS 対応、
canonical／alternate／OG メタデータ、JSON／CSV取得を提供する。音源は保存・再生しない。

英日すべてのcanonicalページを収録し、相互の `hreflang` と `x-default` を持つXMLサイトマップを
ルートに生成して `robots.txt` から参照する。正方形SVG faviconは安定したルートURL
`/favicon.svg` で公開し、全ページから参照する。

全ページのフッターに「問題を報告」リンクを設ける。リンク先は本リポジトリで固定・ロックした恒久
フィードバックIssueとし、GitHubアカウントのない利用者をログイン不要の共通フォームへ案内する。

各詳細ページでは正本の RMS 包絡線からレスポンシブな時間推移 SVG を生成する。表示範囲は
0〜−80 dBFSに固定し、有音判定閾値を示し、表示下限未満の値もJSONには保持されると明記する。
LUFSの時系列や波形であるかのように表現しない。

PCでは長い結果表を画面高に応じたスクロール領域へ収める。列が横方向にはみ出す場合は、通常の
スクロールバーに加えて、常時操作できるキーボード対応の左右移動ボタンを表示する。ラベル付き
カード表示は狭いモバイル画面だけで使用する。

初回アクセス時は、通常OS設定を反映するブラウザの優先言語順から英語または日本語を選ぶ。
利用者が言語を明示的に切り替えた場合はブラウザのローカルストレージに選択を保存し、以後は
自動判定より優先する。言語変更時は現在のページ、クエリパラメーター、フラグメントを維持する。
